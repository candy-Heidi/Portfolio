# 이해영 · AI Systems & ML Serving

통화 음성이 CRM의 업무 기록이 되기까지, AI 추론을 실제 시스템에 연결합니다. GPU 서빙 구축, 전사 품질 평가, 전달 지연 개선과 LLM Agent 평가를 수행했습니다.

## AI 시스템 구축·운영 및 평가

- GPU 서버 1대·GPU 2장 기반 전사 서빙 구조와 기존 웹서버 연동을 구축했습니다.
- 단계별 지연 분석을 바탕으로 웹훅 개선을 우선하고 발송 구조 후보를 비교·채택했습니다. 요약 웹훅 지연 p50 51초→8초, p95 80초→26초를 관측했습니다(적용 후 5영업일 6,945건, 제공 기술 문서 기록). 전체 처리 시간의 개선 수치가 아닙니다.
- ASR 4종·400회 비교 시험과 정답 10건 직접 청취를 바탕으로 오류를 분류하고 모델 선택·전사 후처리에 반영했습니다.
- 기존 CRM Agent의 이력 구성과 도구 호출 동작을 평가했습니다. 첫 라운드 도구 미호출률 55%→30%는 변경 전후 각 60회의 통제 실험 결과입니다.
- Hybrid Search PoC에서 PostgreSQL·pgvector, 키워드·임베딩 검색 결합을 검토했습니다. 운영 미배포입니다.

본인 기여는 문제 정의, 구조 선택, GPU 서빙 구축·연동, 평가 기준과 운영 적용 판단입니다. 구현과 집계에는 AI 코딩 도구를 활용했으며, 기존 웹·CRM·앱의 개발과 팀 협업을 구분합니다.
