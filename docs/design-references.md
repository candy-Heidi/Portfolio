GitHub 자료는 독립적으로 공개된 개발자 사이트·소스입니다. 접근되지 않은 Behance 내용을 우회해서 복제한 자료가 아닙니다.

## 채용 성과의 근거

X 작성자는 자신의 사이트를 보고 면접관이 시니어인 줄 알았다고 말했다는 후기를 게시했습니다. **이는 면접 반응에 대한 본인 진술입니다. 합격·입사·채용 효과를 독립적으로 확인한 것은 아닙니다.**

다른 개발자 자료도 ‘합격자 포트폴리오’로 단정하지 않습니다. 디자인의 인기도나 공개된 개발자 이력만으로 특정 포트폴리오가 합격 원인이었다고 추정하지 않습니다.

## 선택한 방향

**X 영상의 큰 편집형 타이포그래피 + 개발자 포트폴리오의 명확한 정보 구분**을 조합했습니다.

- 영문 이름에 큰 Bodoni 계열 디스플레이체와 이탤릭을 사용해 인물의 인상을 만듭니다.
- 한글 이름·큰 제목은 명조 계열로 대응하고 본문은 읽기 편한 산세리프로 유지합니다.
- 경력·프로젝트·논문은 녹색·라벤더·노란색의 독립적인 챕터 표지로 구분합니다.
- 표지의 그림은 직접 작성한 구분용 SVG 모티프입니다. 실제 실험 결과나 회사 시스템 도식이 아닙니다.
- 인트로 동영상·로딩 화면을 넣지 않습니다. 첫 화면에서 바로 자기소개와 세 섹션을 볼 수 있습니다.
- 본문 18–20px, 모바일 17–18px, 표시 문구 최소 17px을 유지합니다.
- 기본 화면은 짧게, 정식 논문 제목과 전체 구현·검증 내용은 상세에서 펼칩니다.

외부 사이트의 코드, 사진, 영상, 일러스트, 3D 모델을 포트폴리오에 복사하지 않았습니다. 폰트는 Google Fonts가 배포하는 OFL 폰트를 기반으로 변환·이름 변경한 로컬 파일이며 원본 라이선스를 포함했습니다.

## Behance 접속 결과

사용자가 공용 인터넷 접근을 변경한 뒤 X는 HTTP 200으로 접근됐습니다. Behance도 기존 프록시 CONNECT 차단과 달리 원격 HTTP 응답을 받았지만, 검색·갤러리 요청은 403 JavaScript 확인 응답, 일반 Chromium의 페이지 탐색은 HTTP 400/탐색 실패로 끝났습니다.

제공된 프록시와 CA를 사용하고 TLS 검증을 유지했습니다. 인증서 검증을 끄거나 차단된 사이트를 제3자 미러로 읽지 않았습니다. **개별 Behance 작품의 제목·작가·화면을 확인한 상태는 아닙니다.** 최종 Behance 작품 비교는 미완료로 남깁니다.

사용자가 지정한 경로:

- https://www.behance.net/galleries/graphic-design
- https://www.behance.net/search/projects/web%20design%20portfolio?locale=ko_KR

이 검토는 기본 디자인의 근거를 분명히 하기 위한 기록입니다. 원문의 글씨가 작거나 대비가 약한 부분은 사용자의 읽기 기준에 맞춰 변경했습니다.

## v4 시각·모션 시안

사용자가 기존 틀은 유지하면서 시각적인 풍부함과 반응을 요청해, 큰 작업 표지를 중심으로 한 미리보기·선택·기울기·상세 이동과 이미지 중심 목록을 작성했습니다. 표지 사진 출처는 `assets/images/README.md`, 벡터 구성은 `visuals.js`, 동작은 `motion.js`에 있습니다.

Behance 검색 경로를 다시 요청했지만 403 JavaScript 확인 응답이었습니다. Google·DuckDuckGo는 확인/리디렉션 화면, Bing은 주제와 맞지 않는 결과를 반환해 새 레퍼런스로 인용하지 않았습니다. 이번 모션을 특정 Behance 작품에서 검증한 효과라고 주장하지 않습니다. 제공된 X 영상의 짧은 타이포그래피 효과와 동일한 전체 사이트 동작을 확인한 것도 아닙니다.

v4는 요청한 시각·인터랙션 방향을 실제로 조작할 수 있게 만든 독자 시안입니다. 캡처와 함께 실제 브라우저 조작 영상을 제공합니다.
