## 내용의 깊이

기본 화면은 **한 문장 개요 → 역할·방법 2개 → 핵심 결과 → 결과의 조건** 순서입니다. 긴 논문 정식 제목, 구현 방법, 전체 실험 조건은 한 단계 더 펼쳐봅니다.

- `presentation.js`: 짧은 기본 화면 문구.
- `content.js`: 확장된 방법·검증 조건과 원래 경력 근거.
- `docs/presentation-en.md`, `docs/presentation-ko.md`: 기본 화면 문구.
- `docs/content-en.md`, `docs/content-ko.md`: 펼친 설명을 포함한 전체 자료.

중요한 수치 조건은 기본 화면에도 둡니다. 예를 들어 웹훅 p50, Agent 통제 실험, 검색 미배포 PoC 구분은 상세 안에만 숨기지 않습니다.
