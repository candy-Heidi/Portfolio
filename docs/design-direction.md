# 포트폴리오 디자인 방향 · v1

## 결정

**Editorial Systems — 읽기 쉬운 편집 디자인 + 탐색 가능한 AI 시스템 지도.**

밝은 종이색 배경, 짙은 먹색 타이포그래피, 주황색 포인트로 구성한다. 큰 제목으로 정체성을 전달하고, 시스템 흐름을 클릭하면서 본인 기여를 읽게 한다. 홈페이지의 주요 독자는 AI/ML·ML Serving 직무 채용담당자와 기술 면접관이다. **영어가 기본이며 EN/KOR 선택으로 전체 본문을 전환한다.**

이번 결과물은 디자인과 콘텐츠를 함께 검토할 수 있는 동작 시안이다. `index.html`에 구현했다. React/Next.js 전환이나 실제 배포에 앞서 구조·문구·인터랙션을 확인할 수 있다.

## 레퍼런스 조사 상태

- 사용자 지정 출발점: https://www.behance.net/galleries/ui-ux
- 2026-11-11 접속: HTTP 프록시 CONNECT 403, Chromium에서도 `ERR_TUNNEL_CONNECTION_FAILED`.
- 따라서 특정 Behance 작품을 열람·선정했다고 주장하지 않는다. 아래 디자인은 독자 시안이다. 레퍼런스 최종 선정은 미완료다.
- `behance.net`, `www.behance.net` 접근을 환경 설정 초안에 추가했다. 초안 저장은 현재 환경 접근 허용이나 게시 완료를 뜻하지 않는다.
- Behance의 좋아요·추천·시각적 완성도는 취업 합격의 증거가 아니다. 합격자 사례는 공개 채용 후기, 본인의 경력 및 포트폴리오 연결이 확인되는 경우에만 그렇게 기록한다.
- 접근 가능해지면 실제 작품 3개를 보고 제목·작가·URL·참고 요소·모바일 구조·합격 근거 유무를 비교한다. 원본의 이미지·코드·고유 구성을 복제하지 않는다.

## 화면 순서와 콘텐츠 우선순위

1. 소개: 이름, AI Systems/ML Serving 방향, 한 문장 가치 제안.
2. 핵심 근거: 요약 웹훅 지연 개선, ASR 모델 비교, 연구 수상.
3. 전체 흐름: 음성 입력 → GPU 전사 → 요약·전달 → CRM 기록. 품질 평가와 Agent·검색은 연결된 별도 영역.
4. 단계별 기여: 흐름도 버튼 클릭으로 문제·판단·역할·근거·한계 표시.
5. 대표 의사결정: GPU보다 전달 경로를 먼저 개선한 이유. 측정치가 무엇을 뜻하는지 함께 설명.
6. Projects: 기사·이미지 상품 추천, 이미지 의류 검색, WISET RAG를 별도 상세 항목으로 구성.
7. Papers: 학술지 확장 연구, 석사논문, KSC 2025 수상 연구의 문제·방법·결과 및 추가 논문 3편.
8. 소개·학력·기술: 연구에서 운영으로 이어지는 경력, 확인 가능한 기술 묶음.
9. Contact: 사용자 승인에 따라 최신 PDF의 이메일과 GitHub 프로필 링크 표시. 확인되지 않은 LinkedIn URL·논문 링크는 만들지 않는다.

## 인터랙션과 반응형

- PC: 상단 내비게이션과 EN/KOR 선택, 2열 Hero, 가로 운영 흐름, 상세 영역 2열.
- 모바일: 세로 Hero, 세로 운영 흐름, 줄바꿈되는 단계 버튼, 상세 영역 1열, 접을 수 있는 메뉴.
- 클릭·터치·키보드로 단계 선택 가능. 선택 상태는 색뿐 아니라 테두리·텍스트와 `aria-pressed`로도 표시.
- 선택 시 상세 내용을 갱신하고 상태를 스크린리더에 알린다. 사용자의 스크롤 위치를 강제로 바꾸지 않는다.
- 프로젝트와 논문 상세는 기본 HTML `details`로 펼친다. 언어 전환 시 선택한 담당 영역과 상세 펼침 상태를 유지하고, 저장한 언어 선택은 다음 방문에도 적용한다. Escape로 모바일 메뉴를 닫는다.
- 링크는 실제 이동 대상이 있는 것만 사용한다. 지원하지 않는 기능을 가짜 버튼으로 표시하지 않는다.
- 도식은 개인정보가 없는 개념도이며 실제 회사 관리 화면을 재현하지 않는다.

## 배포 선택

**GitHub는 소스 관리, Vercel은 배포**로 선택한다. GitHub Pages에서도 이 정적 시안은 실행 가능하다. Vercel의 장점은 이후 PR별 미리보기, Next.js나 서버 기능 확장, Git 기반 배포 흐름이다. 채용용 설명에서는 호스팅 서비스 이름보다 구축·검증한 과정을 강조한다.

지금은 별도 라이브러리 없이 HTML/CSS/JS로 디자인을 확인한다. 디자인 검토만을 위해 Next.js를 먼저 설치하지 않는다. 실제 배포와 계정 연결은 이번 시안 제작에 포함하지 않는다.
