홈은 자기소개와 Experience / Projects / Papers 목차로 구성합니다. 각 섹션 목록에서 개별 상세 화면으로 들어가며, About·Education은 별도 화면입니다.

Experience는 통합 흐름과 단계별 담당 범위를, Projects는 산학·RAG 구현을, Papers는 주요 연구별 문제·방법·결과를 설명합니다. 이메일과 GitHub는 사용자 승인에 따라 공개합니다. 최신 PDF는 2~3페이지만 사용했으며 첫 페이지 커버레터는 제외했습니다.
