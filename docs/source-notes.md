## 언어

새 방문은 영어 기본. EN/KOR로 본문·메뉴·상세 문구·접근성 설명을 전환합니다. 명시적인 URL `?lang=en` / `?lang=ko`가 가장 우선하며, 다음은 기기에 저장된 선택, 그 외는 영어입니다. 기술명과 브랜드용 영문 장식 문구는 두 언어에서 유지됩니다.

영문 추가 논문 제목은 국문 제목의 설명용 번역입니다. 공식 영문 서지 제목으로 외부 확인하지 않았습니다. DOI·출판사 링크·저자 순서는 제공되지 않았으므로 가짜 링크나 정보를 채우지 않았습니다.

## 성과를 설명하는 범위

- 웹훅 51→8초는 **요약 웹훅 p50**. 전체 E2E 개선이 아님. p95 80→26초, 변경 전 6,241건·후 6,945건(5영업일). 적용 후 원천 데이터 보존 한계를 함께 표시.
- E2E 분석 6,225건과 단계 기여도 6,221건은 다른 모집단. 서버 STT 3.3% 안에 GPU 1.3%가 포함되므로 서로 별개 구간처럼 합산하지 않음.
- ASR 4종·400회와 장문 단건 실험은 운영 정확도 향상으로 바꾸지 않음.
- Agent 미호출률 55→30%는 변경 전후 각 60회의 통제 실험. 142개 시험은 코드 경로 검증이며 결함 개수·운영 품질 지표가 아님.
- Hybrid 52/60은 내부 12질의·Claude 단독 판정이며 MRR@5는 키워드가 높음. 미배포 PoC·기존 CRM 검색 대비 효과 미입증을 표시.
- 상품 추천의 0.45→0.69는 예시 코사인 유사도. 추천 정확도 개선율이 아님.
- 논문 성능은 특정 벤치마크·기준 모델·지표에 한정. 학술대회 연구와 학술지 확장은 연결된 연구로 기술.
