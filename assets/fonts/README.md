# Local display fonts

Display fonts are self-hosted; the website sends no font requests to Google or another provider.

- `portfolio-display.woff2` and `portfolio-display-italic.woff2`: derived from Bodoni Moda, weight 600, distributed by Google Fonts. Source CSS: https://fonts.googleapis.com/css2?family=Bodoni+Moda:opsz,wght@6..96,600;6..96,700&display=swap and the italic family variant.
- `portfolio-serif-kr.woff2`: derived from Nanum Myeongjo Bold, from https://github.com/google/fonts/tree/main/ofl/nanummyeongjo.

Modifications: conversion from TTF to WOFF2 and family/full/PostScript naming changed to **Portfolio Display** / **Portfolio Serif KR** to avoid using reserved upstream names for modified files. Glyphs were not removed. Original copyright and license records are retained in the font data. The complete upstream SIL Open Font License texts are included alongside these files.

Body copy uses the existing system sans-serif stack. The custom faces are for large display text; small captions were not introduced.
